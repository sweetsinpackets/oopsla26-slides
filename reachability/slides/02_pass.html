Functions and Contextual Freshness

At function application, reachability types check separation and controlled sharing.
A function's qualifier is the set of resources it observes. 

  val a = new Ref(1)
  val b = new Ref(2)
  def f(x: Ref[Int]??~{~*}??) = !a + !x
          //: ((x: Ref[Int]??~{~*}??) -> Int)??~{a}??
Contextual freshness: ${\cao\qfresh}$ requires an argument separate from what f observes. 

  f(b)   // ok: `f does not observe b`
  f(!!a!!)   // !!error:!! f already observes a

Controlled Sharing

The argument qualifier names what may be shared with the function. 

  val c = new Ref(3)
  def f(x: Ref[Int]??~{~*a}??) = b := !a + !x
          //: ((x: Ref[Int]??~{~*a}??) -> Unit)??~{a,b}??
  

  f(a)   // ok: `sharing a is allowed`
  f(c)   // ok: `c is separate`
  f(!!b!!)   // !!error:!! f already observes b
(x: T??~{~*}??) shares neither a nor b
(x: T??~{~*a}??) may share a, nothing else
(x: T??~{a}??) within a, nothing fresh
Everything else the argument may reach must stay contextually fresh.
