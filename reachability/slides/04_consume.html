Effects: The Use–Mention Distinction

Reachability records what a term mentions; effects record what it uses. 

  val p = new Ref(0)          //: Ref[Int]??~{p}??
  val q = p                   //: Ref[Int]??~{q}??
  def later() = q := !q + 1   //: (Unit -> Unit | {^^use^^: q})??~{q}??
A function type carries its latent effect: what a call uses and kills. 

  free(p)                     //: Unit | {^^kill^^: p}
  val k = later               // ok: effect ~0, mentions q only
  !!later()!!                     // !!error:!! {^^use^^: q} after {^^kill^^: p}, q reaches p
Mentioning a killed resource is allowed; using it is not.

Move: Ownership Transfer


  val r = new Ref(7)  //: Ref[Int]??~{r}??
  val d = r           //: Ref[Int]??~{d}?? <: Ref[Int]??~{r}??
  val s = move r      //: Ref[Int]??~{~*}??  `s owns it now`
  s := 41             // ok
  !!d := 5!!              // !!error:!! d reaches a moved r
Move kills the old names and hands the resource back fresh.
$\dfrac{\G^{\flt} \ts t : \TRef{T^{\cao q}}^{\,\cao p} \;\; \varepsilon} {\G^{\flt} \ts \textsf{move}~t : \TRef{T^{\cao q}}^{\,\cao\qfresh} \;\; \varepsilon \rhd \{{\ceff\textsf{use}}{:}\,{\cao p};\ {\ceff\textsf{kill}}{:}\,{\cao p}\}} \;\; \rulefmt{t-move}$
The use effect forbids moving twice; the kill effect disables every name reaching p.
