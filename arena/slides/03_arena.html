This Work: Three Allocation Forms

at coallocates into an arena; scoped ties its lifetime to a lexical scope

new Ref(t): Ref[T]♦fresh arena, non-lexical lifetime
new Ref(t) at r: Ref[T]rsame arena and lifetime as r
new Ref(t) scoped: Ref[T]♦fresh arena, lexical lifetime
One reference type for all three, and only the qualifier differs. code written for Ref[T] works with each of them

Arenas: One Identity per Group

An arena needs no handle: any of its references is an entry to it. 

  val fr = new Ref(42)      //: Ref[Int]??~{fr}??
  val a1 = new Ref(7) !!at fr!! //: Ref[Int]??~{a1}?? <: Ref[Int]??~{fr}??
  val a2 = new Ref(8) !!at a1!! //: Ref[Int]??~{a2}?? <: Ref[Int]??~{fr}??
at fr and at a1 add to the same arena.
Coarse-grained: only the arena ℓ is tracked. qualifiers omit the offset of a cell ⟨ℓ, offset⟩

Arenas: Cycles Inside One Arena


  val a  = new Ref(())               //: Ref[Unit]??~{a}??
  val c1, c2, c3 = new Ref(..) at a  //: Ref[..]!!~{a}!!
  c1 := (x: Int) => (!c2)(x)         // ok
  c2 := (x: Int) => (!c3)(x)         // ok
  c3 := (x: Int) => (!c1)(x)         // ok
Cells reach each other via the arena ??{a}??. so adding an edge requires no qualifier growth
Telescoping does not apply inside an arena. so arbitrary store structures are allowed within it

Arenas: Cycles Across Arenas


  val a = new Ref(..)     //: Top??~{a}??
  val b = new Ref(a)      //: Ref[Top??~{a}??]??~{b}??
  val c = new Ref(b) at a //: Ref[Top??~{b}??]??~{c}?? <: Top??~{a}??
  b := c                  // ok: closes the cycle
A cell may reach later cells, if they join an arena already reached. b := c needs only ??{a}??, already in b’s referent
No qualifier grows, so cycles may span arenas.

Lifetimes: Non-Lexical

An escaping arena is tracked as an escaping reference, needing no name of its own.
Two patterns: a fresh arena per call, or one arena shared by all calls. 

  def mk() = {
    val a = new Ref(())
    new Ref(7) at a
  }                 //: () -> Ref[Int]??~{~*}??
  val x1 = mk()     //: Ref[Int]??~{x1}??
  val x2 = mk()     //: Ref[Int]??~{x2}??
A fresh arena per call: x1, x2 disjoint

  val pool = {
    val b = new Ref(())
    () => new Ref(8) at b
  }                 //: () -> Ref[Int]??~{pool}??
  val y1 = pool()   //: Ref[Int]??~{pool}??
  val y2 = pool()   //: Ref[Int]??~{pool}??
One shared arena: y1, y2 reach ??{pool}??

Lifetimes: Lexical

scoped ties an arena to its lexical scope, bulk deallocated at scope exit.
Safe by reachability separation: the result never reaches it, so no downstream use. 

  val r1 = new Ref(0)           //: Ref[Int]??~{r1}??
  val out = {
    val a = new Ref(()) !!scoped!!  //: Ref[Unit]??~{a}??
    val u = new Ref(42) at a    //: Ref[Int]??~{u}??
    val w = new Ref(a) at r1    //: Ref[Ref[Unit]??~{a}??]??~{w}??
    new Ref(!u)                 //: Ref[Int]??~{~*}??   ok
  }   // !!a, u deallocated; w stays in r1's arena!!
w still reaches the deallocated arena.
Inside the scope, a scoped reference is indistinguishable from a non-lexical one.

Lifetimes: Non-Escaping by Reachability

The block’s result must not reach the scoped arena a, directly or via store lookup.
Reaching is not using: w reaches a, but nothing after } can name w.

Minimal condition: the highlighted premise, a reachability separation check. 

  val r1 = new Ref(0)          // `①`
  val out = {                  //: Ref[Int]??~{~*}??
    val a = new Ref(()) !!scoped!!
    val u = new Ref(42) at a
    val w = new Ref(a) at r1   // `②`

  }                            // `③`
may use (φ) deallocated (κ)
① before r1
② inside r1, a, u, w
③ after r1, out a, u

The programmer never writes φ or κ; their disjointness is a proof invariant. details in §5 of the paper; all proofs are mechanized in Rocq

Lifetimes: Scoped Arguments

Case study: a scoped argument is a bracket that cannot leak its resource.

as written


  f(new Ref(..) !!scoped!!)
lifted out of the call ⟶

as it is checked


  {
    val x = new Ref(..) !!scoped!!
    f(x)            // `f needs no annotation`
  }                 // !!x deallocated here!!
      

  def id(y: Ref[Int]??~{~*}??) = y                 //: (y: Ref[Int]??~{~*}??) -> Ref[Int]??~{y}??
  { val z = id(new Ref(1) !!scoped!!); !z }    // ok
Used inside the scope: ok, the block returns an Int.

  { id(new Ref(1) !!scoped!!) }                // !!rejected!!
Returned: rejected, the result reaches the scoped reference.
