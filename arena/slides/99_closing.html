the cycle inside one arena, now in a scoped arena


  {
    val a = new Ref(()) !!scoped!!
    val c1, c2, c3 = new Ref(f) at a
    c1 := (x: Int) => (!c2)(x)
    c2 := (x: Int) => (!c3)(x)
    c3 := (x: Int) => (!c1)(x)
  }   // !!{a, c1, c2, c3} deallocated together!!
Reference counting alone never reclaims this. no count in a cycle ever reaches zero
A scoped arena deallocates all of it. and no value that outlives the block refers into it
